🤖 Jarvis n8n

Assistente inteligente desenvolvido com n8n, integrado ao Telegram, OpenAI, Google Calendar e GitHub.

Funcionalidades

- Recebe mensagens pelo Telegram
- Identifica mensagens de texto, áudio e arquivos
- Transcreve mensagens de voz
- Utiliza IA para interpretar os comandos
- Responde automaticamente pelo Telegram
- Cria eventos no Google Calendar
- Integração com GitHub
- Analisa arquivos enviados pelo usuário

- Tecnologias

- n8n
- OpenAI
- Telegram Bot API
- Google Calendar API
- GitHub API
